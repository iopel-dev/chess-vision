Находит шахматную доску на экране, строит её
виртуальную копию и в реальном времени подсвечивает **зелёным** лучшие ходы
Stockfish 19 (нейросеть NNUE, все ядра CPU, большой хэш).

## Запуск

```
pip install -r requirements.txt
python main.py
```

Если Stockfish не найден в папке `engine/`, он будет скачан автоматически
(или вручную: `python get_stockfish.py`).

## Параметры командной строки

| Флаг | Что делает |
|---|---|
| `--auto-find` | периодически заново искать доску (окно сдвинули, прокрутили страницу, сменили вкладку) |
| `--auto-find-time СЕК` | интервал автопоиска, по умолчанию 5 с; сам включает `--auto-find` |
| `--no-window` | без окна программы: подсветка поверх доски, лучшие ходы печатаются в консоль, выход — Ctrl+C |
| `--gdi` | рисовать подсветку прямо на экране через GDI, без прозрачного окна-оверлея |
| `--external-window [ЗАГОЛОВОК]` | перебирать все окна и искать доску в любом из них; окно снимается через PrintWindow, поэтому доска распознаётся, даже если её окно перекрыто другими. Подсветка ездит вместе с окном и прячется, когда окно закрыто другими окнами. Можно указать часть заголовка окна: `--external-window Arena` |
| `--multipv N` | сколько лучших ходов подсвечивать (1–5) |
| `--auto-turns` | Auto-ходы в консоли: дебют по ходам из книги, дальше каждый ход — лучший ход Stockfish (виртуальная доска, на сайте ничего не нажимается) |
| `--book masters\|lichess\|local\|off` | дебютная книга для Auto: `masters` — партии мастеров из интернета (Lichess Opening Explorer, по умолчанию), `lichess` — игроки lichess 2000+ (может понадобиться токен в `LICHESS_TOKEN`), `local` — встроенная база без интернета, `off` — сразу Stockfish |
| `--book-mode random\|top` | `random` — ход по популярности с весами (каждая партия — новый дебют), `top` — всегда самый частый ход |
| `--move-time СЕК` | время Stockfish на ход в `--auto-turns` (по умолчанию 1 с) |
| `--review [PGN]` | открыть **Virtual Game Review** — разбор партии из PGN (без файла — с начальной позиции или с `--fen`) |
| `--fen FEN` / `--pgn ФАЙЛ` | начать `--auto-turns` с позиции / сохранить партию в PGN |

Примеры:

```
python main.py --auto-find --auto-find-time 3
python main.py --external-window
python main.py --external-window Arena --auto-find
python main.py --no-window --gdi
python main.py --auto-turns --move-time 0.5 --pgn партия.pgn
python auto-turns/auto_turns.py --book local --book-mode top   # то же, что main.py --auto-turns
```

Без интернета (или если lichess ограничил запросы) книга сама переходит на
встроенную базу дебютов.

Про `--gdi`: подсветка рисуется средствами GDI (перья, кисти, Polygon, TextOut)
в собственное нативное Win32-окно поверх доски, без Tk. Рисунок не стирается,
когда окно с доской перерисовывается, мышь проходит сквозь него, и он исключён из
захвата экрана, поэтому стрелки не мешают распознаванию. Если на старой Windows
такое окно создать не удаётся, программа рисует прямо на экране. В этом режиме
подсветка может мерцать, а стрелки без `--external-window` не рисуются, только рамки.

## Как пользоваться

1. Откройте доску на экране — программа сама её найдёт
   (или кнопка **«Выделить вручную»** — обведите доску мышью).
2. **Калибровка**: один раз для каждой программы/набора фигур откройте новую
   партию (начальная расстановка). Программа сама запомнит, как выглядят фигуры
   (`calibration.npz`). Ориентация (белые снизу/сверху) определяется сама.
3. Дальше просто играйте/смотрите: каждый ход распознаётся, виртуальная
   партия ведётся по правилам (очередь хода, рокировки, взятие на проходе).

Лучший ход — ярко-зелёная стрелка «1», следующие — светлее («2», «3»).
Над доской (и вверху окна программы) — строка
`Running Live analysis...   Bestmove is Nf3   +0.25   (depth 22)`;
если доска упирается в верх экрана, строка показывается под ней.

Сделанные ходы программа оценивает, как в разборе партий в шахматных программах:

| Отметка | Значит |
|---|---|
| 🟤 значок `≡` — теория | ход из дебютной теории; название дебюта — в строке над доской |
| 🔷 значок `!!` — блестящий | лучший (или почти) ход с жертвой материала, когда позиция ещё не выиграна |
| 🟢 значок `★` — лучший | ход совпал с лучшим ходом движка или почти не уступает ему |
| 🟠 стрелка `?` — ошибка | позиция заметно ухудшилась, но не решающе (шансы на победу упали на 10–30 %) |
| 🔴 стрелка `??` — зевок | потеря материала или партии, либо допускает мат (шансы упали на 30 % и больше) |

Обычные нормальные ходы никак не отмечаются. Оцениваются два последних хода — так
вердикт вашему ходу виден, даже если бот ответил мгновенно.
Подсветка рисуется и в окне программы, и прозрачным слоем прямо поверх
настоящей доски (мышь проходит сквозь него).

| Кнопка | Что делает |
|---|---|
| Найти доску | заново искать доску на всём экране |
| Выделить вручную | обвести доску рамкой |
| Калибровка | принудительно откалибровать (доска в начальной позиции) |
| Перевернуть | если ориентация определилась неверно |
| Сейчас ход белых / чёрных | если программа начала следить с середины партии и ошиблась в очереди хода |
| Лучших ходов | сколько вариантов (MultiPV) показывать |
| ▶ Auto (самоигра) | доигрывает текущую позицию за обе стороны: пока позиция дебютная — ходы из книги (список «Дебюты»: мастера / игроки lichess из интернета, локальная база, без книги), дальше — лучшие ходы Stockfish. Только на виртуальной доске в окне программы, на сайте ничего не нажимается. Скорость: быстро / средне / медленно (0.3 / 1 / 3 с на ход) |

## Virtual Game Review

Разбор партии на виртуальной доске: кнопка **Virtual Game Review** в окне программы
(берёт партию самоигры Auto или партию с живой доски) или `python main.py --review партия.pgn`.

| Управление | Что делает |
|---|---|
| ⏮ ◀ ▶ ⏭, клавиши ← → Home End, колесо мыши | листать ходы; клик по ходу в списке — перейти к нему |
| ▶ в конце партии | сыграть лучший ход Stockfish |
| ★ Лучший ход (B) | сыграть лучший ход из текущей позиции; если в партии был другой ход — продолжение заменяется |
| ⏵ Авто (пробел) | листать партию самому, а в конце доигрывать её лучшими ходами (скорость: быстро / средне / медленно) |
| Открыть / Сохранить PGN, Перевернуть (F), Новая партия | |

На каждой позиции: зелёная стрелка — лучший ход, оценка и главный вариант Stockfish,
отметка сделанному ходу (`≡` `★` `!!` `?` `??`) и название дебюта. Вся партия
анализируется в фоне отдельным Stockfish (0.4 с на позицию), текущая позиция — первой.

## Как устроено

- `chessvision/detector.py` — поиск доски: квадратные контуры + решётка из клеток,
  проверка шахматного узора 8×8, подгонка к линиям сетки до пикселя.
- `chessvision/recognizer.py` — эталоны 32 фигур, снятые при калибровке; каждая клетка
  сравнивается с эталонами, «пересаженными» на её фон, — так определяются и тип, и цвет
  фигуры (работает с тенями, кремовыми/цветными наборами, светлыми и тёмными досками).
  Порог отличия фигуры от клетки подстраивается под текстуру доски.
- `chessvision/tracker.py` — восстанавливает сделанные ходы (1–2 полухода между кадрами).
- `chessvision/engine.py` — бесконечный анализ Stockfish в фоне.
- `chessvision/explorer.py` — дебютная книга: Lichess Opening Explorer из интернета, запасная локальная база.
- `chessvision/review.py` — Virtual Game Review: разбор партии, навигация, доигрывание лучшими ходами.
- `chessvision/selfplay.py`, `chessvision/autoturns.py` — Auto-ходы: книга, затем Stockfish (окно / консоль).
- `chessvision/overlay.py` — прозрачное окно поверх экрана, исключённое из захвата.
- `chessvision/gdi_overlay.py` — рисование прямо на экране через GDI (`--gdi`).
- `chessvision/winutil.py` — WinAPI: перечисление окон, захват окна через PrintWindow.
- `chessvision/blacklist.py` — чёрный список браузеров, **по умолчанию выключен**
  (`ENABLED = False`). Если включить, доска не распознаётся в окнах браузеров: по имени
  процесса (Chrome, Edge, Firefox, Opera, Яндекс, Brave, Vivaldi и др.), по классу окна
  (Chromium / Firefox / IE, в том числе переименованные и Electron-приложения) и по
  встроенному браузерному движку (WebView2); проверка при поиске доски и на каждом кадре.

Самопроверка без реальной программы: `python -m tests.test_synthetic`
